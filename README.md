## 🛠 Стек технологий и методологий
* **Анализ данных:** SQL / Python (парсинг баз данных, когортный анализ, поиск аномалий, гео-аналитика).
* **Продуктовый подход:** A/B тестирование гипотез, Customer Development, сегментация.
* **Финансы:** Расчет Unit-экономики (МАП/ГАП), прогнозирование ROI и сроков окупаемости.
* **ИИ и Автоматизация:** Google Apps Script (JavaScript), интеграция OpenAI API (`gpt-4o-mini`), Prompt Engineering.

## 📈 Ключевые бизнес-кейсы и продуктовые решения

### 1. Глобальная аналитика: Сегментация рынка и ценовые аномалии
* **Задача:** Максимизация доходности объектов за счет выявления неочевидных закономерностей ценообразования (МАП и стоимость м²).
* **Решение:** Проведен парсинг БД (аренда/продажа). Построены корреляционные модели влияния макро-метрик (трафик, удаленность от метро) и микро-метрик (наличие «мокрых точек», видовые характеристики). 
* **Результат:** Сформирована тепловая карта и матрица базовых цен. Выявлен дефицит микро-кабинетов с автономными коммуникациями, что стало фундаментом для концепции «Анора Маркет».

### 2. Реконцепция объектов (Кейс «Анора Маркет», м. Белорусская)
* **Вводные:** Помещение 110 м² со средней рыночной ставкой офисной аренды 3000-4000 руб./м².
* **Решение:** Объект переформатирован из классического офиса в VIP-коворкинг (нарезка на 4 блока с мокрыми точками) под медицинские и бьюти-услуги на основе выявленного дефицита предложения.
* **Результат:** Достигнута целевая арендная ставка **6000 руб./м²**, обеспечена инвестиционная доходность **(ROI) проекта 17% годовых**.

### 3. Оптимизация арендного потока в стрит-ритейле (Локация: Братеево)
* **Вводные:** Торговая галерея коридорного типа с трафиком 16 500 чел/день.
* **Решение:** Разработана дифференцированная ценовая матрица на основе тепловой карты трафика: 
  * 3500 руб./м² — фасадные зоны (импульсный спрос).
  * 2800 руб./м² — центральная зона (целевые услуги).
  * 2500 руб./м² — тупиковые зоны (якорные арендаторы, ПВЗ).
* **Результат:** Спроектирован оптимальный tenant-mix, исключающий каннибализацию трафика и максимизирующий общую выручку.

### 4. A/B тестирование гипотез (Флиппинг апартаментов)
* **Задача:** Валидация максимальной цены продажи (550 000 руб./м²) для премиум-студий.
* **Решение:** Разработаны концепции упаковки лотов («Квартира для пиджака» vs «Готовый арендный бизнес без окон»). Проведено рыночное тестирование через публикацию тестовых объявлений (Циан/Авито).
* **Результат:** Замер конверсии позволил защитить финансовую модель продажи перед стейкхолдерами на основе реальных данных спроса (Data-Driven подход) до старта сделок.

## 🤖 Инструмент автоматизации: AI-Классификатор недвижимости
Для ускорения обработки входящего потока объявлений был разработан скрипт, интегрирующий языковую модель непосредственно в Google Sheets. 

* **Логика работы:** Скрипт анализирует текстовое описание объекта через API OpenAI (`gpt-4o-mini`) и автоматически отбраковывает неподходящие предложения (офисы, подвалы, помещения без прямого доступа к улице, частичная аренда).
* **Код инструмента:** См. файл `ai_classifier.gs` в данном репозитории.
